# Generadores

Scripts con los que se dibujó el mapa y se fue modificando el mod. Se guardan como referencia: cada `vNN.py` parte del resultado del anterior, así que no forman una compilación de un solo paso.

Necesitan datos extraídos de una copia propia del juego, que **no se incluyen**, además de `numpy`, `opencv-python` y `pillow`. La variable `MM_DOCS` indica la carpeta de trabajo.
